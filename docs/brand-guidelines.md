# 万象影界 | VISTAVERSE 品牌规范

## 品牌身份

**正式品牌名：** 万象影界

**英文品牌名：** VISTAVERSE

**技术代号：** PRINTFILM / `printfilm`

`PRINTFILM` 继续用于 GitHub 仓库、Docker 镜像、环境变量、数据库迁移键、域名和代码标识；用户可见的产品品牌统一使用 **万象影界 | VISTAVERSE**。

## 定位与主张

万象影界是一个从主题和剧本出发，将故事转化为分镜、画面、视频、旁白和成片的 AI 影像创作平台，覆盖 AI 短视频、AI 漫剧、创作工具和开放 API。

**中文主张：** 一念成片，万象可见。

**英文主张：** Turn Every Idea into a World.

**产品说明：** 从一段文字，到一部好片。

## Logo

主 Logo：[vistaverse-logo.svg](./brand/vistaverse-logo.svg)

标准源文件：`frontend/public/logo.png`（人工设计原图，1254×1254 RGBA）

产品端 SVG：`frontend/public/logo.svg`（纯矢量路径描摹，渐变由 SVG 定义）

浏览器图标：`frontend/public/favicon.svg`、`admin/public/favicon.svg`，两者均使用纯矢量路径。

官网主视觉：`frontend/public/hero-3.png`，并覆盖兼容路径 `frontend/public/hero.jpg`。

图形由影像画框、轨道镜头和播放光点组成：画框代表可交付的作品，轨道代表角色、场景和镜头之间的连续创作，播放光点代表从文字到成片的启动瞬间。

使用 Logo 时保持图形比例，不拉伸、不旋转、不添加阴影或外部描边。深色图标适合浅色导航和文档；在深色背景上保留完整深色底块，保证播放光点和轨道对比度。

## 语气

- **有画面感：** 讲清楚故事如何进入镜头。
- **专业可靠：** 说明流程、状态和产出，不夸大模型能力。
- **鼓励创作：** 面向创作者使用直接、积极的动作词。
- **克制清晰：** 少用“魔法”“百分百自动”等无法验证的承诺。
